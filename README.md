# SÜLDE — The Last Banner

**СҮЛД** — premium 3D souls-like action RPG prototype.

The banners of heaven have gone dark. Five remnants remain on the steppe. One ovoo still burns.

Repo: https://github.com/XalMorak/sulde

## Монгол

Souls-like 3D RPG-ийн өндөр түвшний суурь (vertical slice):

- 5 тоглох дүр / класс
- Stamina тулаан (light / heavy / dodge i-frame / sprint)
- Lock-on, poise, flask, үхэл + сүлд алдах/буцааж авах
- Ovoo (bonfire) — дайснууд дахин төрөнө
- Олон дайсан + Khar Sülde босс
- Гуравдагч хүн, сүүдэр, манан, кинематограф UI

Энэ нь бүрэн AAA тоглоом биш. Энэ бол зөв архитектуртай, тоглож болох, цаашид өргөтгөх студийн прототип.

### Дүрүүд

- Noyon / Ноён — greatsword, poise
- Baatar / Баатар — axe, high damage
- Mergen / Мэргэн — bow, range
- Böö / Бөө — staff, tenger-fire
- Kharachin / Харачин — dual blades, i-frames

### Удирдлага

WASD хөдөлгөөн · Shift гүйх · Space dodge
LMB хөнгөн · RMB хүнд
Q lock-on · F flask · E ovoo / сүлд авах
Mouse камер · Esc pause

## Run

```bash
git clone https://github.com/XalMorak/sulde.git
cd sulde
npm install
npm run dev
```
